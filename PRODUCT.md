# Product

## Register

product

## Users

Fleck serves Mac users who want to capture a thought immediately, develop it into a durable note, organize it without friction, and optionally collaborate with a local agent without surrendering ownership of their content. The same person may arrive hurried and keyboard-first through the menu bar, then continue in a pinned window for focused editing. The interface must work equally well for casual note-taking and for dense, repeated use involving folders, tabs, search, formatting, links, Trash, import/export, and accessibility technologies.

## Product Purpose

Fleck is a native, local-first macOS notes workspace. It combines fast menu-bar capture, a real rich-text editor, readable local storage, on-device speech paths, and explicit per-note agent access. Success means the app feels immediate enough to disappear during writing, trustworthy enough for personal material, and coherent enough that advanced features never make the core note workflow feel complicated.

## Brand Personality

Calm, capable, native.

Fleck should feel considered rather than decorated: quiet when the user is writing, precise when the user acts, and gently expressive only when motion clarifies a relationship or confirms a meaningful state change.

## Anti-references

- A web component gallery transplanted into a Mac app.
- Decorative glassmorphism, permanent glow, ambient particles, animated gradients, or blur applied without a structural purpose.
- A SaaS dashboard made of cards, badges, and boxed sections where native macOS hierarchy would be clearer.
- Motion that delays keyboard commands, typing, note switching, search, Undo/Redo, or dismissal.
- Bouncy, elastic, or theatrical transitions on frequently used controls.
- Washed-out toolbar bands, stacked translucent materials, weak contrast, and custom chrome fighting system materials.
- Toolbar consolidation that removes, reorders, or hides accepted commands in the name of visual simplicity.
- Platform mimicry that copies iPhone interactions, web CSS effects, or another product's identity instead of translating the underlying principle to macOS.

## Design Principles

1. **Writing remains the still point.** Chrome may respond around the editor, but typing, selection, the caret, Undo/Redo, and note content never wait for animation.
2. **Native first, custom only with a job.** Prefer macOS structure, controls, materials, focus behavior, menus, sheets, and accessibility semantics before introducing custom visuals.
3. **Motion explains continuity.** Animate identity, origin, destination, hierarchy, and state—not decoration. The more often an interaction occurs, the quieter and faster it becomes.
4. **Progressive depth without hidden power.** Keep the default workspace calm while leaving every accepted command discoverable, keyboard reachable, and spatially stable.
5. **Trust is visible.** Persistence, destructive actions, agent changes, errors, and recovery states use truthful feedback with clear dismissal and no false completion.
6. **One coherent app at every scale.** The menu-bar panel, pinned window, sheets, search, Settings, and packaged application share one component and motion language.

## Accessibility & Inclusion

Fleck targets WCAG AA contrast and native macOS accessibility behavior. Every visual state also has a non-color signal. VoiceOver order, names, values, hints, and announcements must remain meaningful as surfaces change. Reduce Motion replaces spatial movement with a brief crossfade or an instant state change; keyboard-initiated actions are instant even when Reduce Motion is off. Reduce Transparency replaces materials with legible semantic opaque surfaces. The interface must remain usable with increased contrast, larger text, keyboard-only navigation, Full Keyboard Access, Chinese and mixed-script content, and long localized labels.
