# Security policy

## Supported versions

Fleck has not published a supported release. Source snapshots and local
Developer Preview builds receive no guaranteed security updates.

## Reporting a vulnerability

Fleck does not yet publish a verified private vulnerability-reporting channel.
Do not include vulnerability details, private data, credentials, or an exploit
in a GitHub issue or other public discussion.

Before making the repository public, the maintainer must publish and test a
private security contact here. Once the repository is public,
[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository)
can supplement or replace that contact after it has also been tested. This is a
release gate, not a currently available reporting route.

After a private route is configured, this file will identify it and state what
versions are supported. Until then, please keep sensitive details private.

General bugs that do not expose a security weakness may use the bug report
template once issues are open.
