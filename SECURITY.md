# Security policy

## Supported versions

Fleck has not published a supported release. Source snapshots and local
Developer Preview builds receive no guaranteed security updates.

## Reporting a vulnerability

GitHub private vulnerability reporting is not active while this repository is
private. Do not include vulnerability details, private data, credentials, or an
exploit in a GitHub issue, pull request, discussion, or other public channel.

The source preview will be made visible without an announcement. Public issue
and pull-request intake will remain closed until the maintainer enables and
verifies
[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository),
checks maintainer security-alert delivery, and updates this file with the active
reporting route. This paragraph describes the launch sequence, not a currently
available reporting route.

Until that sequence is complete, please keep sensitive details private.

General bugs that do not expose a security weakness may use the bug report
template once issues are open.
