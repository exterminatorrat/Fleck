# Fleck 1.1.2-beta.2 — First public Developer Preview

**Published:** 2026-09-18 · **Version:** `1.1.2-beta.2` · **Distribution:** Developer Preview

This is the first public Developer Preview of Fleck, a native, local-first macOS notes workspace
for quick capture, focused rich-text editing, on-device dictation, and explicitly granted
local agent access. Everything below is written both as a technical changelog and as your
**onboarding guide** — in-app onboarding is intentionally not shipped in this release, so
this document is the place to start.

> **Preview means preview.** This build is a public evaluation milestone, not a stable
> release: features and behaviors may change between previews, and no support or
> compatibility promise applies yet. The next previews and the first official release
> follow the progression ladder in [`../RELEASES.md`](../RELEASES.md).

---

## What is Fleck?

Fleck lives in your macOS menu bar and in a pinned window. It keeps your notes in readable
local storage — no account, no cloud sync, no server. You get a real AppKit rich-text editor,
fast workspace search, note linking, inline images, Apple on-device dictation with an optional
faithful local cleanup pass, and an optional local agent that only does what you explicitly
grant it.

## First launch — get started in about three minutes

1. **Install.** Download the `Fleck 1.1.2-beta.2 Build <number>.zip` asset below, verify it against
   the SHA-256 checksum in the same release, double-click to extract, and drag
   `Fleck 1.1.2-beta.2 Build <number>.app` into **Applications**. If macOS shows a Gatekeeper
   warning, read this release's signing and notarization note before continuing — never
   disable Gatekeeper to force an app open.
2. **Open Fleck.** Launch it from Applications. It is a **menu-bar app**: look for the Fleck
   four-tile mark on the right side of the macOS menu bar and click it to open the workspace.
   (There is no Dock icon to find.)
3. **Write your first note.** In the workspace, create a new note, give it a title, and start
   typing. Your note saves automatically to local storage.
4. **Use dictation when you are ready.** Click the **microphone** at the front of the
   formatting toolbar. The first capture asks macOS for **Microphone** permission so the app
   can use Apple's on-device speech recognition. Your speech is processed locally; nothing
   is uploaded. If the app offers it, a "cleanup" pass runs on-device only where the system
   reports Apple on-device Foundation Model support and is otherwise skipped.
5. **Explore formatting.** Select text, then open the **Text**, **Paragraph**, and **Tools**
   menus in the toolbar. Every control also exists in textual overflow menus and is
   keyboard-reachable.

## What's in this version

### Editor and formatting

- An AppKit `NSTextView` editor with real native undo/redo, attributed selections, and
  readable rich-text persistence (RTF save/reload).
- **Visual text styles:** Normal, Heading 1/2/3, Quote, and Code.
- **Paragraph controls:** alignment (left/center/right/justified), line spacing
  (Single / 1.5 Lines / Double), spacing before/after a paragraph, and list or paragraph
  indentation with real list metadata and renumbering.
- **Formatting helpers:** clear formatting, copy/copy formatting, paste formatting, and
  baseline (Normal / Superscript / Subscript).
- **Unicode-aware case conversion:** Uppercase, Lowercase, and Capitalize with locale-neutral
  Unicode mapping that also protects the note-link and inline-image references in the text
  while converting.
- **A compact, ordered toolbar** with distinct Text, Paragraph, and Tools icon menus, a
  leading microphone, a trailing Delete action, truthful mixed-formatting accessibility
  state, and measured overflow when the panel is narrow.

### Notes, links, images, and search

- **Note links:** type or insert a `[[note title]]` link through the picker; Fleck derives
  backlinks automatically and resolves them without losing formatting.
- **Web links:** insert guarded web links with validated hosts and a canonical target; stale
  targets and attachment-bearing selections are rejected rather than half-applied.
- **Inline images:** drag an image file from Finder (or paste a file URL) into a note. Fleck
  copies valid images up to 100 MiB and 100 million pixels into its local image library,
  keeps the original imported bytes across undo/redo, and fits the display automatically to
  the editor width (320-point height cap).
- **Find and Replace in a note:** `⌥⌘F` opens find, `⇧⌥⌘F` find-and-replace, `⌘G` next
  match, and `⇧⌘G` previous match.
- **Workspace search:** press `⌘F` in the workspace to search all notes. Matching is
  case- and accent-insensitive (for example `cafe` finds `Café`), with highlighted titles
  and snippets and no dependence on system appearance settings.

### Capture, dictation, and agent access

- **On-device dictation:** Apple on-device speech recognition with personal-dictionary
  handling, local text history, and Inbox-safe Smart Capture routing. If routing is
  ambiguous on a supported host, Fleck falls back to keeping the original text or the Inbox
  rather than inventing a destination.
- **Agent Connector (optional):** a separately packaged local helper you install from the
  app's Settings. It has profile-scoped capabilities, **explicit** per-note or per-folder
  grants, visible activity, revision checks, idempotent mutations, and Undo. The app never
  grants itself access.

### Data and privacy

- Notes, tabs, folders, search, backlinks, file shortcuts, a 30-day Trash, import
  (text/Markdown), and export (plain text/Markdown/RTF).
- Atomic local writes with a previous-generation recovery snapshot, so an interrupted save
  does not corrupt your notes.
- No account, no cloud, no telemetry, no background uploads.

## System requirements and compatibility

- **macOS 14** or later is the declared minimum deployment target.
- **Apple silicon** is the platform the current build is validated on. Native Intel
  compatibility and a full macOS 14 native pass have **not** been completed or verified yet.
- The release does **not** include the experimental "Enhanced Local" candidate speech and
  language-model graphs; they remain debug-only and are not approved for distribution.
- Live app behavior is validated through the test suite and CI; this release has not been
  exercised by a public installed user base yet, so treat it as a preview with known
  limitations rather than a supported product.

## Known limitations (read before filing issues)

- This is a Developer Preview: interfaces and storage formats may still change.
- Intel Macs and a full macOS 14 native run are not yet verified.
- Inline images copy as local file references; image content is not embedded in note
  exports.
- In-app onboarding is not shipped; this document is the onboarding.
- Agent and dictation surfaces are local and explicit by design; there is no cloud sync,
  account service, or real-time collaboration.

## Technical notes

- **Stack:** Swift 6, AppKit (`NSTextView`), local-first storage with atomic replacement and
  recovery snapshots; the Agent Connector is a separate local IPC helper over a typed Unix
  socket protocol.
- **Version identity:** `VERSION` is the sole version authority. Every packaging run builds
  an immutable `Fleck <version> Build <number>.app`; the app's build metadata records the
  source commit and build UUID.
- **Verification:** at release time the source passed the full ordinary graph
  (2,543 tests in 37 suites) and the complete Enhanced Local graph (2,754 tests in 40
  suites), plus packaging, model-asset-exclusion, no-launch, symbol, signature, and bundle
  validation checks in hosted CI.
- **Signing and notarization:** the current CI packages in a `ci-unverified` development
  mode. If this release's asset is not yet signed with a Developer ID and notarized, the
  release notes state that explicitly next to the download and macOS's Gatekeeper behavior
  is described there.
