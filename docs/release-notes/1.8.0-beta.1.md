# Fleck 1.8.0-beta.1 — Combined Developer Preview

**Build date:** 2026-11-11 · **Version:** `1.8.0-beta.1` · **Distribution:** local test build

This is the combined preview that collects everything since the first public
Developer Preview (`1.1.2-beta.2`, 2026-09-18). It is a **test build**, not a
published release.

> **Not published, and not signed for distribution.** This build is ad-hoc signed
> with no Developer ID and no notarization, so it cannot be published as a
> downloadable release under [`../RELEASES.md`](../RELEASES.md). The newest public
> download is still `1.1.2-beta.2`, and its notes are in
> [`1.1.2-beta.2.md`](1.1.2-beta.2.md). A GitHub Release for `1.8.0-beta.1` is
> withheld until the artifact can be signed, notarized, and stapled properly.

## This build is still slow

Performance is not where it needs to be yet. Typing in long notes, switching
notes, presenting the panel and animation timing all still feel heavier than they
should, and there are no packaged-app measurements for this build — the
repository's performance baseline marks typing, launch, panel presentation, note
switching, save, idle CPU and resident memory as not captured. Two things did
improve: repeated panel resizing no longer re-posts frame updates, and selection
work over many bullet markers no longer rescans per marker. Treat the rest as
known work in progress, not as an unmeasured claim.

## What is new since the first preview

### Images

- **Edit inline images in place.** Selecting an image shows a dashed outline with
  eight square handles — four corners that keep proportions, four side midpoints
  that change one axis — plus a rotation handle above the image that snaps to
  15-degree steps with Shift. Each completed drag is one undo step, Escape cancels
  it, and size and rotation persist when the note reopens.
- **Copy images as pictures.** Copying an inline image now puts image data on the
  clipboard instead of a local file path, including when the selection also
  contains text. Vivaldi and stock native text views paste both the text and the
  images back; a destination that discards HTML images keeps only the text.

### Editor and formatting

- Bullet markers and their separator space behave as one structural prefix, so
  editing cannot leave `•text`, Backspace at the start of the body removes the
  whole prefix, and smart-delete cannot eat a separator the selection did not
  include.
- Dragging a text selection keeps its formatting through the native pasteboard.
- An optional, default-off scroll-edge blur at the top of the editor, adjustable in
  Settings → Appearance and suppressed by Reduce Transparency.
- Hanging indents with a negative tail indent survive loading, saving, dictated
  appends and agent edits; indent and outdent after an empty marker put the caret
  back on the right side of it.
- No more native blue focus ring anywhere: focus effects are disabled at every
  hosting root, including the menu-bar panel, the pinned window and Settings.

### Notes, folders and search

- Focus returns to the editor after you activate a search result, even when the
  dismissal is delayed or the search surface never finishes detaching.
- Folder renaming keeps an invalid name on screen with its error and focus intact,
  and a newer validation error is no longer cleared by an older save finishing.
- Notes header actions, main-UI buttons and row buttons show a quiet hover
  background and reserve consistent 28-point hit targets.

### Agent Activity

- Recorded agent edits render as a unified line diff: red for removed lines, green
  for added lines, unchanged context in neutral, and spoken labels that do not rely
  on colour. Changes over 400 combined lines or 1 MiB keep the Before/After view.

### Dictation and agent access

- A completed capture can be filed into a chosen note and heading in bounded
  chunks, with an on-disk receipt that resumes after a crash and one undo that
  reverses the whole capture.
- Failed captures offer Try again, Copy text, History and Destination, and no
  longer claim success or an unrelated cause.
- Agents can subscribe to note and task events for one note or folder, with signed,
  receipted delivery, and event observation stays off unless enabled for an
  approved profile.

## Installing this test build

1. Extract the ZIP you were given; do not move the app out of its versioned folder
   until it has been opened once.
2. Drag `Fleck 1.8.0-beta.1 Build <number>.app` into **Applications**.
3. The first launch is blocked by Gatekeeper because the build is ad-hoc signed:
   right-click the app and choose **Open** once, rather than disabling Gatekeeper
   or removing quarantine protection.
4. Fleck is a menu-bar app. Look for the Fleck mark at the right of the menu bar.

## Known limitations

- Performance is not good yet; more work is planned, as described above.
- Inline images are copied as picture data limited to 2048 points on the long edge,
  and the original file is never embedded in the clipboard or in exports.
- Intel Macs and a full macOS 14 pass remain unverified; the validated platform is
  Apple silicon.
- The Enhanced Local candidate graph is a separate, unapproved debug-only graph and
  is not in this build.
- No update feed ships with this build: Sparkle embedding stays held until the
  release-side work is approved.
- This build is ad-hoc signed and not notarized. It is for the maintainer's own
  testing, not distribution.
